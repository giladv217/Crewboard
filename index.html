Pay Rates

These come from your payslip and collective-agreement letter — CrewBoard ships them blank on purpose so a salary figure is never built from someone else's numbers. A blank rate is treated as 0.

1 unit for each day your first leg departs FROM home base, plus 1 unit for each day your last leg arrives AT home base. A same-day round trip earns 2 (out + back); a multi-day layover pairing also earns 2 total (the outbound day, the return day) — the layover days themselves earn nothing.
These rates are saved on this device and apply to every roster period until you change them here.

Flight Status (optional — live operational status on the Roster tab)

Points CrewBoard at your own backend service (a Cloudflare Worker) that keeps a small cache of flight status warm. No API key is entered here — the key stays on the backend. Leave the URL empty and CrewBoard works exactly as before, with no network calls. CrewBoard never contacts a flight-data provider directly, and this status is never used for block hours, credit, or pay — it's shown as separate "✈ live" info on each flight.

Route Block-Hour Estimates (fills in flights missing real times)

Future/unflown legs have no real time data yet, so they show blank. One line per route, e.g. TLV-BUD: 3.4 — any leg missing real block hours will use this as an estimate instead, clearly marked as estimated rather than confirmed. Direction matters if it differs (winds etc.) — add both TLV-BUD and BUD-TLV separately if needed.
Export/import is a plain JSON file containing only your route table — no roster, pay, role, or other settings. It never leaves this device except as a file you save yourself.

Airport UTC Offsets (for "Local Station" roster imports)

Only used when an imported roster's times are in local station time rather than UTC. One line per airport, e.g. BUD: 2 (hours ahead of UTC; use -5 for behind). These are fixed offsets — they don't follow daylight-saving, so a UTC roster export is always more accurate. A leg whose airport has no offset here keeps its block time as unknown rather than guessing.

What If

See exactly what a new flight would do to your predicted salary before you accept it. Uses the same engine as the rest of the app, so the numbers match everywhere else. If you already had a flight scheduled that date, this replaces it — it doesn't add on top.
Crew assignment counts as an unscheduled flight (1.5x incentive, or 2x if it also touches the Shabbat window). A swap doesn't — you were always going to be working that day, just with someone else, so it doesn't earn the "unscheduled" bonus.
Fill in the fields above, then tap Calculate What-If — the old vs. new salary comparison shows up here.

Manage Roster

Check a flight's box if it was unscheduled — its block hours count at 1.5×. Shabbat (Fri 19:00 – Sat 19:00 Israel time) is auto-detected (SHB badge) — capped at 2× if a leg is both unscheduled and Shabbat. Holiday-eve/holiday dates (HOL badge) pay flat 2×. A day's 2nd separate flight activity (2nd ACT badge) pays 1.5× — doesn't apply to one continuous multi-destination trip. From your 14th activity day onward (DUTY + LAYOVER count, standby doesn't), duty days get an extra 1.5× (red badge). Any block hours flown this period above 83h earn a further 1.5×. Cancelled flights (CXL) earn a flat 3h credit.
